# Download tvhome

The **[setup guide](SETUP.md#1-download-and-install-tvhome)** has direct downloads
for macOS and Linux, exact SHA-256 verification commands, and installation steps.

Download the executable for your computer and its checksum. The executable
contains the Home TV app and license notices. Run its `--install` option to put
the command in place, then use it to set up all your TVs and choose optional
background features.

For an existing installation, follow [Updates](SETUP.md#updates).
